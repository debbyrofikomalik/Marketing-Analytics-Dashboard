# Fashion E-Commerce Digital Marketing Analytics
This repository contains a Power BI dashboard analyzing the decline in conversion rate (CR) for a fashion e-commerce platform. It highlights performance across regions, product categories, and campaigns, and provides key insights and recommendations to improve CR in the next three months.

## 🚀 Overview
This project focuses on analyzing a decline in Conversion Rate (CR) for a fashion e-commerce company using Power BI. The goal is to identify key factors affecting performance across regions, product categories, and advertising campaigns, and to provide actionable insights to help the marketing team improve CR within the next three months. The dashboard transforms raw marketing and behavioral data into a structured, interactive business intelligence tool for strategic decision-making.

---

## 📊 Project Highlights
- Performed comprehensive data understanding and defined key marketing funnel metrics (Awareness → Interest → Desire → Action).  
- Conducted deep-dive performance analysis by:
  • Location  
  • Product category  
  • Ad campaign  
  to identify segments contributing to CR decline.  
- Evaluated user behavior trends (CTR, product page views, purchase patterns) and mapped them to actionable insights.  
- Designed and delivered a multi-layered Power BI dashboard, including:  
  • Executive overview  
  • Regional insights  
  • Product analysis  
  • Trendlines  
- Generated strategic recommendations for improving CR by 3–5% in the next quarter.

---

## 🛠️ Tools
- **Python (Jupyter Notebook):** Performed data sanity checks, including duplicate detection, missing value detection and handling, descriptive statistics, outlier identification (boxplots), and data distribution visualization using histograms.
- **Power BI:** Built and refined an interactive dashboard for data storytelling and insight visualization.
